📖 Help & Complete Setup Guide

1. How to Process Matches

  • Paste Payload: Paste your app's raw match score message in Tab 1. The app automatically scans team names, scores, and individual frame rows (Home Player, Visiting Player, Type).
  • Add Signatures: Paste the Base64/DataURL image string for the captain signatures into the signature fields.
  • Review & Approve: Click Review / Edit on any staged match to verify extracted details, view preview thumbnails, and click Save & Approve.
  • Lock Batch: Once all matches are approved, click Lock Batch for Export to generate your clean TSV data stream.

2. Connecting Google Sheets (Google Apps Script)

To let this web app write cleanly to your Google Sheet rows:

  1. Open your target Google Sheet. Set Row 1 headers as: HomeTeam | VisitingTeam | Timestamp | HomePlayer | VisitingPlayer | MatchType | GameNumber | HomeSignature | VisitingSignature
  2. In top menu, click Extensions > Apps Script.
  3. Paste the script code provided below, and save the project.
  4. Click Deploy (top right) > New deployment. Choose type: Web app. Set Execute as: Me and Who has access: Anyone.
  5. Copy the generated Web app URL and paste it into Tab 2 of this hub!

3. Google Apps Script Code (Copy & Paste)

function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var tsvData = e.postData.contents;
    var rows = tsvData.split("\n");
    
    for (var i = 1; i < rows.length; i++) {
      if (!rows[i].trim()) continue;
      var columns = rows[i].split("\t");
      sheet.appendRow(columns);
    }
    
    return ContentService.createTextOutput(JSON.stringify({"status": "success", "rowsAdded": rows.length - 1}))
                         .setMimeType(ContentService.MimeType.JSON);
                         
  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify({"status": "error", "message": error.toString()}))
                         .setMimeType(ContentService.MimeType.JSON);
  }
}
